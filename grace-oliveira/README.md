# Grace Oliveira — Atelier Olfativo

Site institucional da Grace Oliveira Atelier Olfativo: produtos aromáticos,
presentes/kits e identidade olfativa para empresas. React + TypeScript +
Vite + Tailwind CSS v4, com fechamento de vendas via WhatsApp (sem
checkout).

Paleta e tipografia seguem a identidade visual do catálogo GO (off-white,
marrom café, dourado fosco; Cormorant Garamond + Manrope). Fotos de produto
extraídas do catálogo oficial da marca.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `src/App.tsx` — página principal com as seções Início, Sobre, Portfólio e Contato.
- `src/index.css` — estilos globais e configuração do Tailwind.
